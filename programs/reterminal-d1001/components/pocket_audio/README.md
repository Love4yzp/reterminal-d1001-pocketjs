# pocket_audio

Mounts `globalThis.audio` for the D1001 `audio.pcm` capability.

- Four streams, each a 16384-frame stereo ring allocated in PSRAM (256 KiB total). The pure C core owns handles, generations, ring cursors, mixing and event queues. It has no locks and no I2S calls.
- The FreeRTOS adapter owns two mutexes. Lock order is `write_lock` then `state_lock`. The mixer holds `write_lock` across `mix_block` and the blocking `d1001_audio_write`, but holds `state_lock` only while copying the block/committing cursors. `destroy`, `pause` and `stop` take `write_lock` before `state_lock`, so they wait for an in-flight block and cannot expose stale PCM; other operations and the tick latch take only `state_lock`.
- The mixer task runs at priority 10 on core 0 and writes one 1024-frame block at a time. It sleeps on a binary semaphore whenever no stream is playing.
- Accepted 44.1/22.05/11.025 kHz streams mix with 1x/2x/4x linear interpolation. Per-stream volume is 0..256 fixed point; the mixed sample is clipped to s16.
- `writePcm` copies the borrowed ArrayBuffer into the ring and subtracts accepted frames from its `last_free` mirror. Mixer facts enter a pending queue; `pocket_audio_latch` (called from `before_tick`) moves them into the tick-boundary queue and appends `credit` facts. `poll` only drains the latched queue, so facts produced during a tick become visible on the next tick. `stop` flushes PCM without deleting already produced events.
- Each event queue has a fixed capacity of 64. When full, a new `ended` evicts a same-handle `credit`/`underrun` (then any `credit`/`underrun`); a redundant same-handle `underrun` is merged; `credit` is a latest-value fact and is coalesced. A saturated `underrun` merge is lossy and increments `dropped_events`; other unavoidable losses also increment it. The adapter compares the cumulative counter against its last reported value and logs at most once per second.
- `pocket_audio_args.c` checks every QuickJS conversion (`JS_ToInt32`, `JS_ToFloat64`, ArrayBuffer/detached state) and returns `JS_EXCEPTION` before any stream state is touched. A valid zero-length ArrayBuffer is accepted as zero frames.
- `pocket_audio_teardown` stops the mixer, clears every handle, disables the codec/PA and frees the PSRAM rings. The next runtime can create fresh streams without leaked handles.
- `src/pocket_audio_core.c` is host-testable and contains the four-stream sequential state machine, ring/credit helpers, mixer stepping and tick-boundary event queues. `tests/pocket_audio_core_test.c` runs under `bun test tools/pocket-audio.test.ts` and covers all nine ops, dual-stream pause/stop isolation, generation reuse, stop/reuse races, queue saturation, lost-fact reporting and latching. The same command compiles `tests/pocket_audio_args_test.c` against QuickJS for Symbol, throwing `valueOf`, non-ArrayBuffer, detached-buffer, zero-length buffer and missing-argument failures. The QuickJS case requires the managed `quickjs-ng` source fetched by an IDF build; when `managed_components` is absent, that case is reported as skipped by `test.skip`.
